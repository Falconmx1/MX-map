# 🚀 MX-map

> *"Más que un escáner, una declaración de guerra silenciosa"*

`MX-map` es una herramienta de reconocimiento de red y escaneo de puertos diseñada para ser **más rápida**, **más sigilosa** y **más personalizable** que Nmap. Creada por y para la comunidad hispana.

![Version](https://img.shields.io/badge/version-1.0.0-red)
![Python](https://img.shields.io/badge/python-3.8%2B-blue)

## 🧨 Características

- Escaneo SYN, TCP, UDP y ICMP.
- Detección de OS y servicios.
- Escaneo paralelo con hilos.
- Banner grabbing avanzado.
- Exportación a JSON/XML/CSV.
- Soporte para proxies y evasión de IDs.
